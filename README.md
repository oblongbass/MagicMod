# 魔法模组 Magic Mod

## 模组概述 / Mod Overview

魔法模组是一个为 Minecraft 1.21.5 设计的 Fabric 模组，为游戏添加了丰富的魔法元素和神秘生物。这个模组专注于提供独特的魔法体验，让玩家能够探索神秘的魔法世界，使用强大的魔法物品，并与特殊的魔法生物互动。

Magic Mod is a Fabric mod designed for Minecraft 1.21.5 that adds rich magical elements and mystical creatures to the game. This mod focuses on providing unique magical experiences, allowing players to explore mysterious magical worlds, use powerful magical items, and interact with special magical creatures.

## 核心特色 / Core Features

### 🎯 魔法物品系统 / Magical Item System

#### 1. 魔法星星 (Magic Star)
- **获取方式**：从魔法僵尸掉落（35%几率）
- **用途**：合成其他魔法物品的基础材料
- **特点**：散发着微弱的光芒，蕴含着神秘的能量

- **Obtainment**: Drops from Magic Zombies (35% chance)
- **Usage**: Basic material for crafting other magical items
- **Features**: Emits faint glow, contains mysterious energy

#### 2. 悬浮魔法杖 (Levitation Magic Wand)
- **功能**：对生物使用可施加悬浮效果
- **使用方式**：右键瞄准生物
- **效果**：目标生物会悬浮在空中7秒
- **视觉效果**：华丽的粒子效果和音效
- **合成配方**：
  ```
    魔法之星    木棍    魔法之星
    魔法之星    木棍    魔法之星
  ```

- **Function**: Applies levitation effect to creatures
- **Usage**: Right-click while aiming at a creature
- **Effect**: Target creature levitates for 7 seconds
- **Visual Effects**: Magnificent particle effects and sounds
- **Crafting Recipe**:
  ```
    Magic Star   stick   Magic Star
    Magic Star   stick   Magic Star
  ```

#### 3. 水晶球 (Crystal Ball)
- **功能**：
  - **普通右键**：扫描周围15格内的生物，显示名称和距离
  - **潜行右键**：随机占卜，提供趣味提示
- **合成配方**：
  ```
    魔法之星    紫水晶碎片    魔法之星
                  红石粉
    魔法之星    紫水晶碎片    魔法之星
  ```
- **冷却时间**：2秒

- **Functions**:
  - **Normal Right-click**: Scans creatures within 15 blocks, displays names and distances
  - **Sneak Right-click**: Random divination, provides fun hints
- **Crafting Recipe**:
  ```
    Magic Star    Amethyst Shard    Magic Star
                     Red Stone
    Magic Star    Amethyst Shard    Magic Star
  ```
- **Cooldown**: 2 seconds

#### 4. 魔法指南书 (Magic Guide Book)
- **获取方式**：首次加入世界时自动获得
- **内容**：完整的模组使用指南和说明
- **功能**：右键查看详细的模组介绍和使用方法

- **Obtainment**: Automatically received when first joining the world
- **Content**: Complete mod usage guide and instructions
- **Function**: Right-click to view detailed mod introduction and usage methods

### 👹 魔法生物 / Magical Creatures

#### 魔法僵尸 (Magic Zombie)
- **生成条件**：
  - 在亮度小于5的黑暗区域生成
  - 在主世界自然生成
  - 每5秒尝试在玩家周围24-48格范围内生成
- **特性**：
  - 比普通僵尸更强大（25点生命值，4点攻击力）
  - 在阳光下会燃烧
  - 掉落魔法星星（35%几率）
- **外观**：特殊的僵尸变种，带有魔法粒子效果

- **Spawning Conditions**:
  - Spawns in dark areas with light level less than 5
  - Naturally spawns in the Overworld
  - Attempts to spawn every 5 seconds within 24-48 blocks around players
- **Characteristics**:
  - Stronger than regular zombies (25 health, 4 attack damage)
  - Burns in sunlight
  - Drops Magic Stars (35% chance)
- **Appearance**: Special zombie variant with magical particle effects

## 安装说明 / Installation Instructions

1. 确保已安装 Fabric Loader 和 Fabric API
2. 将魔法模组 JAR 文件放入 mods 文件夹
3. 启动游戏并享受魔法冒险！

1. Ensure Fabric Loader and Fabric API are installed
2. Place the Magic Mod JAR file into the mods folder
3. Launch the game and enjoy the magical adventure!
